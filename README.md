# Node/Express Starter Template

Une base prête à l'emploi pour démarrer rapidement des projets Express avec
PostgreSQL et Prisma.

Utilise les boutons ci-dessus pour consulter la documentation complète dans la
langue de ton choix.

## Aperçu rapide

```bash
npm install
cp .env.example .env
# renseigner DATABASE_URL dans .env
npm run db:setup
npm run server
```
